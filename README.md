# Portafolio Profesional Web — Hernandez Roman Matias

Sitio web personal desarrollado desde cero aplicando arquitectura CSS modular, maquetación HTML5 semántica y JavaScript vanilla orientado a accesibilidad (A11y) y alto rendimiento.

## 🚀 Demo en Vivo
- **URL del proyecto:** [https://tu-usuario.github.io/mi-portafolio/](https://tu-usuario.github.io/mi-portafolio/)

## ✨ Características
- **100% Accesible:** Navegación por teclado completa, salto de contenido, ratios de contraste WCAG AA.
- **Rendimiento Optimizado:** Puntuación 95+ en las 4 categorías de auditoría de Google Lighthouse.
- **CSS Modular:** Arquitectura de 7 archivos CSS basada en variables sin dependencias de frameworks.
- **Interactividad Native:** Menú interactivo, toggle para Modo Oscuro y validación de formulario JS.

## 🛠️ Tecnologías
- HTML5 Semántico
- CSS3 (Flexbox, Grid, Custom Properties)
- JavaScript ES6+
- Git & GitHub Pages
